## Caveats

- The 300 km Tignes - Val d'Isere linked-domain terrain is modeled only as pass-product scope; this PR does not copy it into local Tignes ski-area piste facts.
- Reviewed sources did not provide local-only Tignes piste kilometers, lift count, or blue/red/black kilometer splits suitable for the current single ski-area entity.
- Stay-base coordinates, nearest-lift distance, lodging price, rental price, quality tier, and supported skill levels remain estimate-backed pending a dedicated stay-base/rental sweep.
- Exact season windows remain unchanged; the linked-domain season needs a separate season-window curation decision.
