## Caveats

- The existing single ski-area id was retained to avoid a weather/climatology evidence migration; the official pass and lift pages support treating Livigno as one local ski area for this curation pass.
- Official Skipass Livigno sources support 115 km and 31 lifts; Skiresort.info lists 32 lifts, so the catalog uses the official operator page and notes the reviewed-source discrepancy.
- Official pages publish slope difficulty labels and run counts, but not kilometers by difficulty; no piste_km_by_difficulty split was added.
- Lodging price range, stay-base quality tier, supported skill levels, rental price range, rental quality tier, and atmosphere tags remain estimates pending dedicated policy or source sampling.
