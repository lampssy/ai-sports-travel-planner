# Saalbach Hinterglemm Catalog Curation - scoped local owner and Skicircus extension

Corrects PR #15 against the normalized catalog and schema-version-2 scope contract. The retained ski-area ID remains the Saalbach Hinterglemm weather owner; whole-Skicircus terrain, season, feature totals, and map claims are removed from that narrower owner. Hinterglemm is added as a sourced stay base with direct Reiterkogelbahn access. Leogang, Fieberbrunn, and the connected Skicircus terrain domain are explicitly deferred as one weather-owner migration, while Ski ALPIN CARD retains its official 408 km / 121-lift pass-accessible aggregate.
