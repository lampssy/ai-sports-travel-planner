## Caveats

- Official Cervino lift-status page includes sub-area timetable rows that do not all share the same operating dates; the catalog uses the official winter tariff/full-area window for destination planning and records this as verified_with_adjustment.
- Italian-side Cervinia/Valtournenche terrain metrics use reviewed editorial evidence because the official pages reviewed in this sweep did not expose a stable static piste-km and difficulty table.
- The Cervinia-Zermatt international pass references the existing Matterhorn Ski Paradise terrain domain; this PR does not edit shared-domain aggregate metrics.
- Lodging price range, stay-base quality, supported skill levels, rental price range, rental quality, and rental lift-distance remain product-curated estimates.
