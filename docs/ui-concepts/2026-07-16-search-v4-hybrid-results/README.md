# Search V4 Hybrid Results Concept

This folder contains the accepted desktop direction for the Snowcast Search V4
results experience.

## Files

- `01-hybrid-results-expanded-desktop.jpg`: accepted results-board concept with
  the first and second recommendation groups expanded and the third group
  collapsed.

## Design Decisions Shown

- compact midnight search command header;
- narrow search-context and refinement rail;
- grouped ski-region recommendations;
- intent-aware `Trip essentials` metrics;
- independently expandable recommendation groups;
- separate `View dossier` navigation;
- neutral evidence surfaces with restrained alpenglow and powder atmosphere;
- green reserved for supported evidence and amber reserved for cautions.

The concept is a design reference, not a production screenshot. Values and
example destinations illustrate the target hierarchy and interaction model.
