# Search V4 Web Experience

Accepted visual references for the Snowcast Search V4 planning flow.

1. `01-homepage-command-stage.png` - initial command stage with the trip brief,
   parsed state, and a concrete example recommendation.
2. `02-hybrid-results-expanded-desktop.jpg` - grouped recommendation board with
   independent expansion, contextual refinement, and comparable trip metrics.
3. `03-dossier-results-navigator.jpg` - desktop dossier with a collapsible
   master-detail recommendation navigator.
4. `04-dossier-snow-evidence.jpg` - month-only climatology evidence section.
5. `05-dossier-full-page.png` - full dossier hierarchy and accommodation
   handoff.

Interactive references:

- Homepage: <https://p.superdesign.dev/draft/0db8c1de-23d7-496a-9a00-9b55b1d58a31>
- Results: <https://p.superdesign.dev/draft/fd59ea10-da9e-4260-a72a-e75dbe5d4e2e>
- Dossier: <https://p.superdesign.dev/draft/6338f0ff-0694-49f3-9abc-57a782d7b50a>

The images are directional UI references rather than data fixtures. Resort,
weather, score, price, and evidence values shown in them are illustrative and
must be replaced with typed product data during implementation.
